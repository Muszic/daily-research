## World Action Agent: Harnessing VLMs for Robot Manipulation via World Action Rehearsal

### Problem

General-purpose Vision-Language Models (VLMs) possess broad knowledge and spatial reasoning abilities, yet existing approaches for robot manipulation fail to fully leverage these strengths or introduce new challenges:
1.  **Indirect Control:** Many systems use VLMs indirectly to predict constraints, write programs, or provide high-level guidance, rather than allowing them to directly control the robot based on their spatial understanding. This limits direct VLM decision-making.
2.  **Weakened General Reasoning:** Fine-tuning VLMs for direct action prediction (VLAs) can degrade their general understanding and multimodal reasoning capabilities, hindering generalization to new tasks.
3.  **Inadequate Visual Interfaces:** Prior visual interfaces for direct VLM control (e.g., Show-Harness, VIA) display the scene but lack a "world for the VLM to act in." Specifically, they suffer from:
    *   **Non-centered Observation:** Views are not focused on the immediate interaction (gripper-object-target relations), making fine-grained discernment difficult.
    *   **Lack of Action Verification:** Actions are irreversible upon execution, preventing the VLM from previewing or revising their consequences before committing.
    *   **Disjoint Perception-Action Space:** Observed visual offsets require translation into different coordinate systems for correction, breaking the intuitive feedback loop.
4.  **Limited Embodied Knowledge:** VLMs typically lack the specific embodied procedural knowledge required for robust robot manipulation.

This paper addresses the core question: **How can a general-purpose VLM use basic action primitives to make and revise decisions throughout execution, effectively serving as a robot pilot?**

### Method

The paper introduces **World Action Agent (WAA)**, a multi-agent embodied harness that enables frontier VLMs to pilot robots directly using basic tools. WAA's core innovation is a **visual action workspace** with three key properties, along with mechanisms for acquiring embodied knowledge:

1.  **Interaction-Centered Canvas (Contact Views):**
    *   Instead of fixed global views, WAA automatically selects and optimizes **Contact views** that focus on the current interaction region (gripper, object, target).
    *   These views are chosen to maximize visibility, encourage compact framing, and provide orthogonal perspectives (e.g., front and side views) to reveal fine local relations.
    *   Crucially, the entire Canvas (global + contact views) retains its projection calibration, allowing image-space annotations to map directly to 3D robot commands.

2.  **Agentic World Action Rehearsal:**
    *   Actions are treated as **editable proposals** rather than immediate commands.
    *   The VLM localizes targets on the Canvas and specifies a target pose. The harness then performs inverse kinematics, plans the motion (e.g., with cuRobo), overlays the proposed robot configuration as a translucent preview on all views, and reports its feasibility (e.g., collision, reachability).
    *   The VLM (or an **Imagination Agent** it delegates to) can iteratively examine the approach direction, prospective contact, and surrounding clearance in the visual preview, and revise the pose until a feasible plan is found, all *before* any physical action.

3.  **In-View Correction:**
    *   To address residual errors from depth noise, calibration inaccuracies, or contact disturbances, WAA provides a closed-loop execution mechanism.
    *   After a planned motion, if the VLM observes a residual offset in a calibrated Contact view, it can directly "drag" or adjust the object's position within that view.
    *   The harness converts these in-view corrections into precise end-effector motions, allowing for fine alignment errors to be removed directly where they are observed.

4.  **Learning through the Harness:** WAA acquires embodied procedural knowledge in two ways, leveraging the same visual action workspace:
    *   **Multimodal Skill Evolution:** It evolves a library of reusable multimodal skills from expert videos (e.g., LIBERO-90) and human teaching. An **Editor** and **Reviewer** process extracts actions and spatial cues, refining them into procedural knowledge with reference images. A **Skill Agent** retrieves and consults these skills during execution.
    *   **VLM Distillation:** Interaction traces (Canvas + control context → tool call) generated by the main VLM piloting the harness are collected. These traces are then used to fine-tune smaller, open-source VLMs (e.g., Qwen3.5-9B) to learn to pilot the *same harness*, effectively distilling the larger VLM's decision-making process.

### Impact

1.  **State-of-the-Art Performance:** WAA achieves a state-of-the-art 75.6% average success rate on the challenging LIBERO-Pro benchmark, significantly outperforming existing end-to-end VLAs, code-as-policy agents, and visual-harness baselines with the same VLM backbone.
2.  **Enhanced Transferability:** The skills evolved only from LIBERO-90 demonstrations prove effective and transferable to the robosuite environment without any further learning, demonstrating robust generalization.
3.  **Effective VLM Distillation:** Fine-tuning a smaller VLM (Qwen3.5-9B) on WAA's interaction traces drastically improves its out-of-domain success rate from 1.7% to 43.3%. This highlights the harness's ability to structure decision-making in a way that is learnable by less powerful models, making VLM-driven robotics more accessible.
4.  **Direct and Intuitive VLM Control:** WAA successfully demonstrates how general-purpose VLMs can directly pilot robots with basic tools by operating within a unified visual action workspace, leveraging their inherent spatial reasoning for both planning and fine-grained correction without requiring complex program generation or costly fine-tuning that compromises their generality.
